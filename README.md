# Personal Academic Website

Astro-based personal academic website prepared for GitHub Pages.

## Routes

- `/`
- `/about/`
- `/projects/`
- `/writing/`
- `/writing/:slug/`
- `/contact/`

The Projects section is reserved and intentionally contains no public project details in the first version.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
